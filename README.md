# 이자비용·감가상각비 분석적절차 MVP

상장기업의 당기·전기 비용과 관련 공시를 수집하여 위험평가 분석적절차를 지원합니다. **실제 오류 또는 중요왜곡표시위험을 확정하지 않습니다.** Python 3.10 이상, 12월 결산기업을 대상으로 합니다.

## 어떤 과정을 거쳐 분석하나요?

사용자가 **회사명과 분석연도**를 입력하면, Python이 재무자료를 수집하고 비용의 변동을 계산합니다. AI를 사용하는 경우에는 검색된 공시 발췌를 읽어 변동을 설명할 수 있는 사실과 가설을 구분합니다. 마지막으로 수치·분석·근거를 **Excel 파일로 자동 저장**합니다.

> 회사명·연도 입력 → 당기·전기 재무자료 수집 → 비용 증감 계산 → 관련 공시 탐색 → 선택적 AI 원인 분석 → 근거가 충분한 경우 기대값 계산 → 추가 감사절차 제안 → Excel 출력

### 1. 같은 기준의 당기·전기 비용을 수집합니다

OpenDART에서 회사명 또는 종목코드로 상장기업을 식별하고, 분석연도와 직전연도의 연간 재무자료를 가져옵니다. 기본은 연결재무제표이며, 사용자가 별도를 선택하면 별도 자료만 사용합니다.

재무자료에서 이자비용과 감가상각비를 찾고, 각 금액의 연도·통화·공시 접수번호를 함께 보관합니다. 원하는 계정이 없으면 해당 사업보고서의 감사보고서 주석을 탐색하여 관련 부분을 발췌합니다. AI를 사용할 때는 발췌에서 누락된 비용 금액을 추출할 수 있지만, 숫자·단위·연도·원문 인용 검증을 통과해야 반영됩니다. 확인되지 않은 금액은 `자료 없음`으로 남깁니다.

### 2. Python으로 증감액·증감률을 계산합니다

- **증감액 = 당기 비용 − 전기 비용**
- **증감률 = 증감액 ÷ 전기 비용의 절댓값**
- 기본 탐색 기준은 **절대 증감률 20% 이상이면서 절대 증감액 10억원 이상**입니다.

예를 들어 이자비용이 100억원에서 130억원으로 증가하면 증감액은 30억원, 증감률은 30%이므로 관련 공시 탐색 대상이 됩니다. 이 수치는 기능 설명을 위한 가상 예시입니다. 비용 감소도 같은 기준으로 탐색하고, 전기가 0원이면 증감률을 만들지 않고 금액 기준을 적용합니다. 당기·전기의 계정 수집 경로가 다르면 비교를 유보합니다.

### 3. 비용 변동과 관련된 공시를 찾아 근거를 모읍니다

연간 감사보고서에서 두 계정의 관련 주석을 발췌합니다. 유의적인 변동이 있거나 비용 금액이 확인되지 않은 계정은 분석연도에 제출된 추가 공시도 제목 키워드로 검색합니다.

| 계정 | 탐색하는 내용 | 분석에서 확인할 관계 |
| --- | --- | --- |
| 이자비용 | 차입금, 사채, 금리, 상환, 차환 관련 내용 | 차입 규모·기간·금리 변화가 비용 변동을 설명할 수 있는가 |
| 감가상각비 | 유형자산, 내용연수, 건설중인자산, 준공, 가동, 설비투자 관련 내용 | 자산의 취득·처분 및 실제 사용개시가 상각비 변동과 연결되는가 |

검색은 설정된 건수와 발췌 범위 안에서 수행합니다. 모든 관련 공시를 찾아냈다고 간주하지 않으며, 공시명·공시일·접수번호·URL·발췌 원문을 결과에 남깁니다.

### 4. AI가 확인된 사실과 원인 후보를 구분합니다

AI 사용 시 두 계정의 수치와 공시 발췌를 묶어 한 번에 전달합니다. AI는 **공시로 확인된 사실, 변동 원인 후보, 공시만으로 확인할 수 없는 사항, 잠재적 왜곡표시위험 후보, 추가 감사절차**를 정리합니다.

이자비용은 신규 차입·회사채 발행, 기존 차입 상환·차환, 차입금리와 기간 변화 등을 검토하도록 요청합니다. 감가상각비는 설비 취득·처분, 공장 준공·사용개시, 건설중인자산 대체, 상각방법·내용연수 변경 등을 검토하도록 요청합니다. 단순히 투자계획이 공시되었다는 이유로 설비 사용이 시작되었다고 가정하지 않습니다.

사실에 붙인 인용문이 전달한 원문에 실제 존재하는지 검사하고, 일치하지 않는 사실 인용은 제외합니다. 다만 인용 일치가 원인 해석의 정확성까지 보증하는 것은 아닙니다. AI가 없거나 실패해도 수치 분석과 공시 발췌, Excel 출력은 계속합니다.

### 5. 근거가 충분할 때만 간단한 기대값을 계산합니다

AI가 원문에서 식별한 입력값을 검증한 후, 실제 산술 계산은 Python이 수행합니다.

| 계정 | 필요한 자료 | 간단한 기대값 계산 |
| --- | --- | --- |
| 이자비용 | 원금, 연이율, 비용 발생기간 | 원금 × 연이율 × 해당 연도 발생기간 비율 |
| 감가상각비 | 취득원가, 잔존가치, 내용연수, 사용가능일, 정액법 적용 근거 | (취득원가 − 잔존가치) ÷ 내용연수 × 해당 연도 사용가능 기간 비율 |

연간 계정 전체를 설명하는 기대값일 때만 실제 비용과의 차이를 계산합니다. 특정 신규 차입이나 설비 한 건에 대한 기대값은 **증분 기대값**으로 표시하고 전체 비용과 직접 대사하지 않습니다. 금리 비교 자료가 있으면 기존·신규 금리 차이도 계산하지만, 통화·만기·담보 등 조건이 다를 수 있으므로 단순 차이만으로 비정상이라고 판단하지 않습니다.

현재 MVP는 기대값 입력 금액이 원 단위, 날짜가 ISO 형식으로 인용문에서 직접 확인되는 경우만 계산합니다. 필요한 조건이 부족하면 추정치를 임의로 만들지 않습니다.

### 6. 추가 확인사항과 감사절차를 제안합니다

설명되지 않은 변동은 확정된 오류가 아닌 검토 대상으로 남깁니다. 예를 들어 이자비용에는 차입금 명세·은행조회서·계약서 대사, 약정금리 재계산, 미지급이자 기간귀속 및 자본화 검토를 제안할 수 있습니다. 감가상각비에는 자산 명세·취득 및 처분 증빙 대사, 준공·검수와 사용가능일 확인, 내용연수·잔존가치·상각 계산 검토를 제안할 수 있습니다.

### 7. 분석 결과를 Excel로 자동 출력합니다

`--output`에 지정한 경로로 **.xlsx 파일 하나, 시트 두 개**를 생성합니다. 별도의 Excel 설치 없이 파일을 만들 수 있습니다.

| 시트 | 저장되는 내용 |
| --- | --- |
| **분석적절차 결과** | 계정별 당기·전기 금액, 증감액·증감률, 공시 확인 사실, AI 원인 후보, 기대값·실제값 차이와 적용 범위, 금리 비교, 위험 후보, 추가 감사절차, 미확인사항, 분석 상태, 금액 출처 |
| **관련 공시 근거** | 관련 계정, 공시명, 공시일, 접수번호, DART 원문 URL, 발췌 인용문, 출처 ID, 연결·별도 구분과 보고연도 |

금액·증감률에 숫자 서식을 적용하고, 헤더·필터·틀 고정으로 표를 읽기 쉽게 구성합니다. 자료 누락, AI 미사용·실패, 비교 유보 상태도 표시하므로 빈 결과를 정상 분석 완료로 오해하지 않도록 합니다.

## 설치·실행

```bash
pip install -r requirements.txt
```

`.env.example`을 `.env`로 복사하고 `OPENDART_API_KEY`를 설정합니다. AI를 사용할 때만 `OPENAI_API_KEY`, `OPENAI_MODEL`을 설정합니다. 모델 기본값은 `gpt-4.1-mini`이며 계정에서 사용할 수 있는 구조화 응답 지원 모델로 변경할 수 있습니다. 키는 Git에 올리지 않습니다.

```bash
python main.py --company "삼성전자" --year 2025 --output "분석결과.xlsx"
python main.py --company "삼성전자" --year 2025 --no-ai --output "수치분석.xlsx"
python main.py --company "가상기업" --year 2025 --demo --output "가상예시.xlsx"
```

`--basis CFS`가 기본이며 별도는 `--basis OFS`입니다. 자동 대체하지 않습니다. 기준은 **절대 증감률 20% 이상 AND 절대 증감액 10억원 이상**입니다. 감소도 탐색합니다. 전기 0은 증감률을 계산하지 않고 금액 기준으로 탐색합니다.

```bash
python main.py --company "삼성전자" --year 2025 --pct 0.15 --amount 500000000 --rate-pp 1.0
```

## 처리 방식

- OpenDART API 하나만 사용합니다. 기업코드 → 연간 전체 재무제표 → 해당 접수번호의 연결/별도 감사보고서 → 유의적 변동 관련 주요 공시 순입니다.
- 이자 지급액을 이자비용으로, 감가상각·무형자산상각 통합액을 감가상각비로 대체하지 않습니다. 명확한 계정이 없으면 주석을 탐색합니다. AI 미사용 시 주석 발췌는 제공하지만 주석 금액의 의미 추출은 수행하지 않습니다.
- AI는 두 계정의 발췌를 묶어 **최대 1회** 호출합니다. 통신 실패나 인용 오류에 재질문하지 않습니다. 확인 사실·원인 후보·미확인사항·위험 후보·추가 감사절차를 구분합니다. 인용문 및 수치의 원문 존재 여부만 확인하며 의미의 정확성을 보장하지 않습니다.
- 비용 기대값은 근거가 있는 입력만 Python으로 계산합니다. 이자: 원금×연이율×연중 해당 일수/연간 일수. 감가상각: (취득원가−잔존가치)/내용연수×사용가능 기간 비율(정액법). 단위가 원이고 날짜가 ISO 형식으로 직접 확인되는 경우에 한합니다. 실제 약정의 일수계산 관행과 차이가 있을 수 있습니다.
- 개별 신규 차입·설비 기대값은 증분 분석으로 표시하며 연간 전체 비용에서 빼지 않습니다. 금리 비교는 통화·만기·담보 등 조건 차이 확인을 요구합니다. 공장 투자 결정만으로 사용개시를 가정하지 않습니다.
- 원문·성공한 API 응답과 AI 결과를 `.cache/`에 저장합니다. 정정공시 반영을 다시 확인하려면 새 `--cache` 경로를 사용하거나 기존 캐시를 삭제하세요. 키와 오류 응답은 캐시에 저장하지 않습니다.

## 결과: 정확히 두 시트

1. **분석적절차 결과**: 비용, 증감, 확인 사실, 원인 후보, 기대값·차이, 금리 비교, 위험 후보, 추가 절차, 상태.
2. **관련 공시 근거**: 계정, 제목, 공시일, 접수번호, URL, 원문 인용 및 출처 ID.

`--demo`는 실제 기업과 무관한 합성 예시입니다. 이자비용 100억→130억(증가 30억·30%), 감가상각비 200억→260억(증가 60억·30%)을 출력합니다. 실측 자료가 없으면 `자료 없음`이며, 0으로 채우지 않습니다.

## 한계 및 검증 범위

최소 기능 제품으로, 모든 기업의 사용자 정의 계정명·주석 배치를 지원하지 않습니다. 감사보고서 첨부에서 연결/별도 구분이 확실하지 않으면 주석 수집을 생략합니다. 감가상각비의 사용권자산 포함 범위, 비용 기능별 배분, 자본화와 비용 인식의 차이는 원문 확인이 필요합니다. 금액 수집 경로가 연도별로 다르면 비교를 유보합니다.

추가 공시는 분석연도 중 제출된 제목 키워드 일치 공시 중 최근 8건, 연간 감사보고서는 계정별 최대 4개 발췌를 사용합니다. `--max-filings`, `--max-excerpts`로 늘릴 수 있습니다. 검색 범위 밖·발췌 누락 가능성이 있으며 “원인 미확인”은 “원인이 없음”을 뜻하지 않습니다. 이후 공시나 종속기업의 별도 공시까지 전수 검색하지 않습니다.

검증: 합성 OpenDART 응답으로 수집·공시발췌 연결, 증감 계산, 기대값 계산, 인용 검증 및 모의 AI 응답의 Excel 2개 시트 저장을 확인했습니다. **실제 OpenDART 키를 사용한 통신, 실제 OpenAI 모델 응답, 모든 기업의 주석 추출은 미검증**입니다. `--demo` 실행에는 어떤 외부 API도 호출하지 않습니다.

공식 자료: [OpenDART](https://opendart.fss.or.kr/guide/main.do), [OpenAI 구조화 응답](https://developers.openai.com/api/docs/guides/structured-outputs).
