# 이자비용 Overall Test — 감사 분석적절차 MVP

**이자비용만 분석합니다.** 회사명과 연도만 입력하면 전기 이자비용과 평균 차입잔액을 이용해 추정 차입이자율을 계산하고, 당기 차입잔액으로 **기대이자비용**을 산출합니다. 실제 장부상 이자비용과 비교한 **절대차이가 10억 원을 초과하거나(OR), 실제 이자비용의 전기대비 절대변동이 전기 실제 이자비용의 10% 이상일 때** 차입·사채 관련 공시를 검색합니다.

> 공개 공시자료 기반 **간이 Overall Test**입니다. 완전한 실증적 분석적절차나 감사의견을 대신하지 않습니다. 실제 기업별 DART 주석 구조에 따라 자료가 누락될 수 있으며, 확인되지 않은 수치를 만들어내지 않습니다.

## 1. 감사 절차 및 검색 조건

**계산 → 판정 → 관련 공시 확인** 순서를 엄격히 따릅니다.

1. **전기 기준:** 전전기말·전기말 이자발생부채로 전기 평균 차입잔액을 산출합니다.
2. **추정 차입이자율:** 전기 이자비용을 전기 평균 차입잔액으로 나눕니다. 양 기간의 차입원가 자본화 금액을 확인할 수 있으면 이자비용을 자본화 전 기준으로 조정합니다. 이 비율은 **실제 개별 차입계약의 금리를 가중평균한 값이 아니라 회계자료로 계산한 추정 평균 이자부담률**입니다.
3. **기대값:** 전기 추정 이자부담률 × 당기 평균 차입잔액으로 당기 기대이자비용을 계산합니다. 자본화 전 기준을 적용했다면 당기 자본화 차입원가를 차감합니다.
4. **장부금액 대사:** 당기 실제 이자비용 − 당기 기대이자비용으로 차이를 계산합니다.
5. **수용가능 차이 평가:** 실제−기대 절대차이 금액 기준 또는 전기대비 실제 이자비용 절대변동 기준 중 **하나 이상(OR)** 충족하면 공시검색 단계로 진행합니다.
6. **관련 공시 후속 검토:** 그때만 `차입금`, `사채`, `회사채`, `증권발행실적보고서`, `차환`, `상환` 등의 공시를 찾고 원문 발췌, 날짜, 접수번호, URL을 기록합니다. 공시를 발견했다는 사실만으로 잔여 차이가 설명됐다고 결론내리지 않습니다.

### 계산식

```text
전기 평균 차입잔액 = (전전기말 이자발생부채 + 전기말 이자발생부채) ÷ 2
당기 평균 차입잔액 = (전기말 이자발생부채 + 당기말 이자발생부채) ÷ 2

전기 추정 평균 차입이자율 = 전기 이자비용 ÷ 전기 평균 차입잔액
당기 기대이자비용 = 당기 평균 차입잔액 × 전기 추정 평균 차입이자율

차이 = 당기 장부상 이자비용 − 당기 기대이자비용
차이율 = |차이| ÷ |기대이자비용|
전기대비 변동 = 당기 실제 이자비용 − 전기 실제 이자비용
공시검색 = (|차이| > 10억원) OR (|전기대비 변동| ≥ |전기 실제 이자비용| × 10%)
```

**차입원가 자본화가 확인되면** 위 이자비용을 자본화 전 기준으로 계산하고, 마지막 기대값에서 당기 자본화 차입원가를 뺍니다. 확인할 수 없다면 비용화 기준의 근사치를 사용하되 한계를 표시합니다.

**두 기준은 별도로 표시합니다:** 실제−기대 절대차이 금액 기준은 10억원 **초과**, 전기대비 절대변동 기준은 `|전기 실제 이자비용|×10%` **이상**입니다. 정확히 10억원인 차이만으로는 검색하지 않으며, 전기대비 정확히 10% 증가 또는 감소하면 검색합니다. 기대값 대비 차이율은 참고용이며 검색 조건에 사용하지 않습니다. 전기대비 변동은 자본화 조정 전의 장부상 실제 이자비용끼리 비교합니다.

각 조건은 독립적으로 평가하므로 기대값이 누락되어도 전기대비 조건을 충족하면 검색합니다. 기대값이 0이어도 금액 조건을 평가합니다. 전기 실제 이자비용이 0이면 변동률은 표시하지 않고 위 금액식 그대로 0원 기준과 비교합니다(당기도 0이면 `0 ≥ 0`으로 검색). 필요한 값이 누락된 조건은 충족으로 처리하지 않습니다. 두 비교를 하나의 `max(...)` 허용차로 합치지 않습니다. 이는 **프로젝트 내부 공시추적 기준**이며 감사인이 정한 중요성 또는 허용차이가 아닙니다.

## 2. 실행

Python 3.10 이상 필요. [OpenDART](https://opendart.fss.or.kr/guide/main.do)에서 API 키를 발급받아 `.env.example`을 `.env`로 복사한 뒤 입력합니다. OpenAI 결제나 별도 AI 키는 필요하지 않습니다.

```bash
pip install -r requirements.txt

python main.py --company "LG에너지솔루션" --year 2025 --output "LG_이자_Overall_Test.xlsx"
python main.py --company "대한항공" --year 2025 --basis OFS --output "대한항공_별도.xlsx"
```

`--amount`는 실제−기대 절대차이의 초과 기준, `--pct`는 전기 실제 이자비용 대비 절대변동의 이상 기준입니다.

기본 옵션: `--basis CFS`, `--pct 0.10`, `--amount 1000000000`, `--max-filings 10`. `.cache`에 OpenDART 응답이 캐시되며 재검증 시 `--cache`로 새 경로를 지정할 수 있습니다.

## 3. 결과 Excel

| 시트 | 주요 내용 |
|---|---|
| **Overall Test** | 전기·당기 평균차입잔액, 전기 추정 이자율, 당기 기대값, 장부상 실제, 차이·참고 차이율, 전기대비 변동·변동률, 두 비교기준, 공시검색 여부, 추가 감사절차 |
| **관련 공시 검토** | 기준 충족 여부, 공시로 차이가 설명되는지에 대한 평가, 공시명·일자·접수번호·URL·원문 발췌 |

기준을 충족하지 못하면 관련 공시 시트에는 **검색을 생략한 이유**만 남습니다. 기본 재무제표와 감사보고서 주석 수집은 Overall Test에 필요한 선행 자료이며, **신규차입·사채 관련 사건공시 검색은 차이 판정 이후**에만 발생합니다.

## 4. 공시가 차이를 설명하는가?

공시명·일자·원문에서 차입이나 사채 발행 사실이 확인됐다는 것과 **전체 이자비용 차이가 정량적으로 설명된다**는 것은 다른 주장입니다. 이 프로그램은 공시 원문의 주요 부분을 확인하고 **확인된 차입·상환 사실, 설명 가능성, 확인 불가 항목**을 분리해 검토합니다. 개별 계약의 발행원금·금리·정확한 실행일, 기존채무 상환과 차환 효과까지 공시로 확인할 수 없는 경우에는 **설명 미완료**로 표시합니다. 자동으로 감사위험이나 오류를 확정하지 않습니다.

필요한 추가 감사절차에는 **차입금명세와 은행조회서·약정서 대사, 계약별 원금×기간×금리 재계산, 유효이자율, 기간귀속, 차입원가 자본화, 외화차입·리스부채·연결범위 영향 검토**가 포함됩니다.

## 5. 신뢰성 및 범위

- 매년 전기와 당기의 **동일 연결/별도 기준**을 사용합니다. 연간 사업보고서의 원본 수치 및 주석 중 명확히 식별되는 금액만 사용합니다.
- 차입금은 연결/별도 재무상태표의 명확히 식별되는 이자발생부채를 집계하며 **단순 평균잔액**을 사용합니다. 회사별 항목 명칭이 다르면 자동 계산이 유보될 수 있습니다.
- `이자비용`과 `이자 지급액` 또는 `금융비용 전체`는 서로 대체하지 않습니다.
- 전기·당기 이자비용의 회계 범위, 차입원가 자본화, 변동금리, 차입·상환의 정확한 시기, 외화환산 및 연결범위 변경이 근사치에 영향을 줍니다. 특히 회사 간·기간 간 추정이자율을 실제 계약상 가중평균금리로 해석해서는 안 됩니다.
- **공시 검색은 조건 충족 후에만** 동일 기업의 해당 사업연도 사건공시를 대상으로 진행하며 제목 키워드 기반의 제한된 검색입니다. 종속기업의 공시까지 전수 검색하지 않습니다.
- 공시의 내용만으로 전체 차이가 검증되지 않으면 **설명 불충분**으로 표시하고 필요한 원장·계약서 자료를 제시합니다.
- 현재 테스트는 합성 자료에 대한 단위·흐름 테스트입니다. 실제 OpenDART 통신 및 모든 사업보고서의 주석 형식까지 포괄하는 통합 테스트는 수행되지 않았습니다.

## 소스 코드

- `core.py` — 전기 추정 이자율, 당기 기대값, 차이·차이율 및 **실제−기대 절대차이 10억원 초과 OR 전기대비 실제 이자비용 절대변동 10% 이상 조건**
- `opendart.py` — 회계정보 선행 수집과 **조건 충족 후 사건공시 검색**
- `main.py` — 정해진 분석 순서와 Excel 생성
- `tests/test_core.py` — 기준 경계값과 **공시검색 호출 순서** 테스트

실행에 필요한 API 키는 `.env`에만 보관하고 GitHub에 업로드하지 마세요.
