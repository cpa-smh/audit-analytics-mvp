# 이자비용 감사 보조 도구

**코드가 차이를 계산하고, AI가 감사기준서에 근거한 추가 감사절차를 작성하며, 차입 관련 공시는 별도로 정리합니다.** 결과는 Excel 3개 시트입니다. 기대값 대비 높음·낮음은 회계상 과소·과대계상 확정이 아닙니다.

## 분석 흐름

1. 동일 연결/별도 기준의 재무제표와 금융비용 주석에서 기초자료를 수집합니다.
2. 기대이자비용, 실제 이자비용, 차이금액과 전기대비 변동을 코드로 계산합니다.
3. AI는 차이 방향에 맞는 추가 감사절차·필요 증빙을 제안하고, 확인된 감사기준서 문단을 근거로 붙입니다.
4. 차입·사채·차환·상환·채무보증 등 공시는 **추가검토 기준 충족 여부와 무관하게** 별도로 수집합니다. AI는 제공된 원문 발췌를 요약하고 감사 참고사항을 작성합니다.
5. Excel에는 기준서의 일반적인 요구사항/적용지침과 AI가 제안한 구체적인 수행절차를 별도 열로 표시합니다. 공시를 차이 원인으로 자동 확정하거나 설명금액을 산출하지 않습니다.

## Excel 구성

| 시트 | 주요 내용 |
|---|---|
| 이자비용 차이 분석 | 원자료, 평균 차입잔액, 추정 이자율, 기대값, 실제값, 차이, 전기대비 변동, 추가검토 기준, 차이 방향, 사업보고서 링크 |
| 추가 감사절차 | 차이 방향, AI 생성 상태, 검토사항, 제안 절차, 필요한 증빙, 기준서·문단, 근거 요약, 근거 확인 경로 및 기준서 게시목록 링크 |
| 차입 관련 공시 | 검색기간·상태·범위, 공시명·일자·접수번호, 클릭 가능한 DART 원본 링크, 원문 발췌, AI 요약, 감사 참고사항 |

### 차이 방향에 따른 절차

- **실제값 < 기대값:** 미계상 이자비용·미지급이자, 기간귀속, 과도한 자본화 가능성을 검토하고 실제 상환·금리 하락도 확인합니다.
- **실제값 > 기대값:** 중복·기간귀속 오류, 자본화 대상의 비용 처리 가능성을 검토하고 차입 시점·금리 상승·차환 중복기간도 확인합니다.
- **일치:** 일치만으로 적정성을 결론내리지 않고 자료 신뢰성과 기대값의 정확성을 검토합니다.
- **산정 불가:** 누락 자료를 확보하고 기초자료를 대사하는 절차를 먼저 제안합니다.

모든 절차는 감사인 검토용 초안입니다. 경영진 질문만으로 종결하지 않고 답변을 뒷받침하는 적합한 증거가 필요합니다.

## 계산식과 추가검토 기준

```text
전기 평균 차입금 = (전전기말 차입금 + 전기말 차입금) / 2
당기 평균 차입금 = (전기말 차입금 + 당기말 차입금) / 2
전기 추정 이자율 = 전기 실제 이자비용 / 전기 평균 차입금
당기 기대이자비용 = 당기 평균 차입금 × 전기 추정 이자율
차이 = 당기 실제 이자비용 − 당기 기대이자비용

양 기간 자본화액을 확인한 경우:
전기 추정 이자율 = (전기 실제 이자비용 + 전기 자본화액) / 전기 평균 차입금
당기 기대이자비용 = 당기 평균 차입금 × 전기 추정 이자율 − 당기 자본화액

추가검토 표시 = (|실제 − 기대| > 10억원)
             OR (|당기 실제 − 전기 실제| >= |전기 실제| × 10%)
```

기존 OR 계산과 경계값은 유지합니다. 정확히 10억원인 차이만으로는 기준을 충족하지 않으며, 전기대비 정확히 10% 증가·감소하면 충족합니다. 기대값 대비 차이율은 참고용입니다. 이 기준은 **프로젝트 내부 기준**으로, 감사기준서가 정한 중요성 또는 감사인이 승인한 허용차이가 아닙니다. 이제 공시 수집을 막는 조건으로 사용하지 않습니다.

각 비교는 독립 평가합니다. 기대값이 없어도 전기대비 조건은 평가하고, 기대값이 0이어도 금액 조건은 평가합니다. 전기 실제가 0이면 변동률은 정의하지 않지만 금액식의 0원 기준은 그대로 적용합니다(당기도 0이면 `0 >= 0`으로 표시). 필요한 값이 누락된 비교는 충족으로 처리하지 않습니다.

## 설치 및 실행

Python 3.10 이상. `.env.example`을 `.env`로 복사하여 키를 설정합니다.

```bash
pip install -r requirements.txt
python main.py --company "LG에너지솔루션" --year 2025 --output "LG_이자비용_감사검토.xlsx"
python main.py --company "대한항공" --year 2025 --basis OFS --no-ai
```

```dotenv
OPENDART_API_KEY=발급받은_OpenDART_키
OPENAI_API_KEY=발급받은_OpenAI_API_키
OPENAI_MODEL=gpt-4o-mini
```

- `OPENDART_API_KEY`: 재무제표·공시 수집용. [OpenDART](https://opendart.fss.or.kr/guide/main.do)에서 발급합니다.
- `OPENAI_API_KEY`: 실제 AI 감사절차 작성·공시 요약에 필요합니다. OpenAI API 사용료가 발생합니다. 공개 공시 발췌, 계산값, 회사 메타데이터, 기준서 요약을 OpenAI Responses API에 보내며 `store=false`를 사용합니다.
- 키가 없거나 `--no-ai`이면 계산·공시 수집은 수행하되 **기본 절차 예시(AI 생성 아님)**와 원문 발췌를 출력합니다. API 오류·불완전 응답·잘못된 인용은 **AI 생성 실패**로 표시하고 기본 예시로 대체합니다. AI가 생성한 것처럼 표시하지 않습니다.
- `--model`: Structured Outputs를 지원하는 모델 지정. 기본은 `OPENAI_MODEL` 또는 `gpt-4o-mini`입니다.
- 기존 옵션: `--basis CFS`, `--amount 1000000000`, `--pct 0.10`, `--max-filings 10`, `--cache .cache`.
- `--amount`는 실제−기대 절대차이의 **초과** 기준, `--pct`는 전기 실제 이자비용 대비 절대변동의 **이상** 기준입니다.

기존 Python/OpenDART 실행방식을 유지합니다. 대화의 MyDART MCP 연결이 로컬 CLI에 자동 연결되지는 않습니다. 키는 저장소에 커밋하지 않습니다.

## 감사기준서 근거 관리

`audit_standards.json`에는 2026-11-06 MyKIFRS `get_paragraph`로 원문을 확인한 문단의 **요약**과 출처를 보관합니다.

| 문단 | 구분 | 사용 목적 |
|---|---|---|
| 520-5 | 요구사항 | 기초자료 신뢰성, 기대치 정확성, 수용 차이 평가 |
| 520-7 | 요구사항 | 차이에 관한 경영진 질문, 관련 감사증거 입수, 기타 필요 절차 |
| 500-A35 | 적용지침 | 원천·입수상황·통제에 따른 증거 신뢰성 검토 |
| 330-A5 | 적용지침 | 위험에 대응하는 검사·질문·조회·재계산 등 절차 유형 |

AI는 이 목록의 문단 ID만 선택할 수 있습니다. 문단명·근거 요약·출처 링크는 코드가 연결하며, 공시 접수번호도 입력 목록과 대사합니다. [한국공인회계사회 기준서 게시목록](https://www.kicpa.or.kr/board/list.brd?boardId=acc0102)은 **문단 직접링크가 아닙니다**. 문단번호와 조회키를 함께 표시합니다. 배포 시 해당 업무에 적용되는 최신 판본·시행일을 확인하여 근거 파일을 갱신해야 합니다.

감사기준서가 개별 자본화 회계처리 요건을 규정하는 것으로 표시하지 않습니다. 구체적인 수행절차는 기준서 일반 원칙을 해당 분석에 적용한 제안이며, AI 내용의 타당성은 감사인이 검토합니다.

## 범위 및 한계

- 기초·기말 단순평균과 전기 이자부담률로 계산한 근사값입니다. 실제 계약별 가중평균금리가 아닙니다.
- 전기 원보고서와 당기 비교표시가 다르면 경고합니다. 원보고서 값이 확인되면 이를 우선 사용합니다.
- 공시는 해당 법인의 해당 사업연도 제출분 중 제목 키워드와 일치하는 최신 건수만 발췌합니다. 전체 차입 이슈·뉴스·종속기업 공시를 전수 검색하지 않습니다.
- 공시 원문 전체가 아닌 제한된 발췌를 AI에 제공합니다. 원문 링크에서 맥락을 확인해야 합니다. 검색 실패와 검색 범위 내 미발견을 구분합니다.
- AI는 계산값을 변경하지 않으며, 공시만으로 차이 원인·과소/과대계상·감사의견을 확정하지 않습니다.
- 외부 API의 실제 인증·가용성·AI 문장 품질은 환경에 따라 달라집니다. CI는 네트워크 없이 합성자료와 모의 AI 응답으로 검증합니다.

## 소스와 테스트

- `core.py`: 결정론적 계산, 차이와 OR 추가검토 표시. `needs_disclosure_search`는 기존 호출자용 별칭이며 공시 수집 제어에 사용하지 않습니다.
- `audit_ai.py`: 차이 방향별 AI 초안, 문단·접수번호 검증, 명시적인 비AI 대체 예시.
- `audit_standards.json`: 원문 확인에 기반한 문단 요약·조회키·출처·확인일.
- `opendart.py`: 재무제표·감사보고서 주석 및 독립 공시 수집.
- `main.py`: 분석·AI 연결과 3개 시트 Excel 작성.

```bash
python -m unittest discover -s tests -v
python -m compileall -q .
```

AI 요청 형식: [OpenAI Structured Outputs 공식 문서](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses).
