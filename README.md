# 이자비용 분석적절차 · Overall Test

회사명과 사업연도를 입력하면 OpenDART의 재무제표·감사보고서 주석·관련 공시를 활용하여 **이자비용의 전기 대비 증감, 기존·신규 회사채 금리 비교, 기대이자비용 추정, 실제 금액과 차이, 추가 감사절차**를 Excel로 정리하는 Python 프로그램입니다.

**검증 범위:** 공개 공시를 이용한 **근사 Overall Test / 위험평가 보조도구**입니다. 차입금 전체의 계약별 일별 잔액, 변동금리 재설정, 유효이자율과 상환계획을 모두 재계산한 완결된 실증적 분석적절차는 아닙니다. 부족한 데이터는 추정하지 않고 미확인으로 표시합니다.

## 수행 과정

1. **재무자료 수집** — 당기·전기 이자비용, 재무상태표 차입금 관련 잔액, 감사보고서 주석을 조회합니다. 연결(CFS)이 기본이며 별도(OFS)를 선택할 수 있습니다.
2. **유의적 변동 선별** — 이자비용 증감액·증감률을 구합니다. 기본 선별조건은 **절대 증감률 20% 이상 AND 절대 증감액 10억원 이상**입니다. `--pct 0.10`으로 10%로 변경할 수 있습니다. 
3. **관련 공시 탐색** — 차입, 사채, 상환, 차환, 증권신고서, 증권발행실적보고서 등의 공시명·공시일·접수번호·DART URL·원문 발췌를 저장합니다. 공시 제목과 제한된 발췌로 검색하므로 완전한 모집단 검색은 아닙니다.
4. **회사채 금리 비교** — 감사보고서 차입금·사채 주석에서 확인되는 **원화 고정금리 사채**의 전기말·당기말 잔액과 표면금리를 사용해 기존·신규·당기말 구성의 원금가중 금리를 구합니다. 전기말에 없던 사채를 신규 후보로 분류하지만 차환이나 연결범위 변경 여부를 확정하지 않습니다.
5. **사채별 기대 쿠폰이자(부분 추정)** — 원금·금리·기간이 확인되면 `원금 × 표면금리 × 해당연도 일수 / 연간 일수`를 계산합니다. 발행일이나 금리 확인이 불가능하면 계산을 유보하며, **부분 쿠폰이자의 합계를 회사 전체 기대이자비용으로 해석하지 않습니다.**
6. **공시 기반 Overall Test(항상 실행)** — 차입 관련 재무상태표의 전전기말·전기말·당기말 잔액으로 평균 이자발생부채를 구하고, **전기 추정 이자부담률**을 **당기 평균잔액**에 적용해 이자비용의 전체 수준 기대값을 추정합니다. 차입원가 자본화 금액을 파악할 수 있으면 비용화 전후를 조정합니다. 자본화 자료가 없으면 비용화 기준의 더 거친 근사값을 제시하고 해당 한계를 표시합니다.
7. **실제 금액과 차이 확인** — 실제 이자비용과 기대값의 차이를 계산하고, `max(절대기준, 실제 금액×상대기준)`을 넘으면 추가 검토 대상으로 표시합니다. 상대기준 기본값은 **5%**이며 이는 감사기준서상 중요성이나 허용오차를 자동 산정한 것이 아닙니다.
8. **추가 감사절차 제안** — 차입금명세, 은행조회서, 계약서 대사, 차입·상환일과 일별 잔액, 변동금리, 미지급이자 기간귀속, 사채할인발행차금, 차입원가 자본화, 리스·연결범위 변동을 검토하도록 제안합니다. 선택적으로 AI가 공시의 확인 사실·원인 후보·미확인 사항을 분리해 분석합니다.

### 근사 Overall Test 계산

```text
전기 평균 이자발생부채 = (전전기말 잔액 + 전기말 잔액) / 2
당기 평균 이자발생부채 = (전기말 잔액 + 당기말 잔액) / 2

전기 추정 이자부담률
  = (전기 이자비용 + 전기 자본화 차입원가) / 전기 평균 이자발생부채

당기 기대이자비용
  = (전기 추정 이자부담률 × 당기 평균 이자발생부채)
    - 당기 자본화 차입원가

차이 = 당기 실제 이자비용 - 당기 기대이자비용
```

관련 자료가 없어 자본화 금액을 반영하지 못하면 자본화 전 금액이라고 표시하지 않고, 이자비용만을 이용한 별도의 근사 비교임을 안내합니다.

## 실행 방법

Python 3.10 이상 필요. `.env.example`을 `.env`로 복사하고 `OPENDART_API_KEY`를 입력합니다. `OPENAI_API_KEY`는 **선택적 AI 공시 해석**에만 필요합니다.

```bash
pip install -r requirements.txt

# AI 없이도 이자비용 Overall Test 수행
python main.py --company "LG에너지솔루션" --year 2025 --no-ai --output "LG_이자분석.xlsx"

# AI 공시 해석 포함
python main.py --company "대한항공" --year 2025 --output "대한항공_이자분석.xlsx"

# 증감 선별 10%·10억, Overall Test 검토기준 3%
python main.py --company "대한항공" --year 2025 --pct 0.10 --amount 1000000000 --overall-tolerance 0.03

# 별도재무제표 분석
python main.py --company "대한항공" --year 2025 --basis OFS --output "대한항공_별도.xlsx"
```

12월 결산 상장기업의 완료된 사업연도를 분석합니다. `--demo`는 실제 공시가 아닌 합성 예시이며 Overall Test는 수행하지 않습니다.

## 구현상 한계

- 현재 전체 수준의 기대값은 기초·기말 단순평균잔액과 전기 추정 부담률을 활용합니다. 개별 계약별 일별 원금, 이자율 변경과 외환·리스·연결범위 영향은 자동으로 완전히 반영하지 않습니다.
- 금리 비교는 확인 가능한 **원화 고정금리 회사채**에 한정됩니다. 원화 은행차입, 외화·변동금리 차입금과 리스의 가중평균금리까지 계산한다는 의미가 아닙니다.
- 회사별 공시 표 구조 및 계정명이 다르므로 일부 수치는 계산되지 않을 수 있습니다. 원자료 확인 없는 추정 대입은 하지 않습니다.
- AI 분석은 선택 기능이며, 공시에서 확인된 사실과 가설을 구분하지만 자체 판단이 감사증거의 충분성을 보장하지 않습니다.
- GitHub Actions 자동 테스트는 합성 데이터와 `--demo` 기준입니다. 실제 OpenDART API 통신과 개별 상장기업 전체에 대한 통합 검증은 별도로 필요합니다.
- 분석상의 차이는 추가 검토 신호이지 회계오류 또는 중요왜곡표시위험 확정이 아닙니다.

## 소스 코드

- `main.py` — 이자비용 수집·변동 선별·공시 검색·Overall Test 연결·Excel 생성
- `dart.py` — OpenDART 재무제표·공시·이자비용 추출
- `overall.py` — 차입잔액 기반 근사 기대값, 원화 사채 금리 비교, 부분 이자 계산
- `ai.py` — 선택적 AI 설명, 원문 인용 확인 및 개별 이자 계산
- `tests/test_overall.py` — 합성 자료 기반 단위 테스트

자료 출처: [OpenDART](https://opendart.fss.or.kr/guide/main.do).
