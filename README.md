# 이자비용·감가상각비 분석적절차 — 공시 기반 Overall Test MVP

기업명·사업연도를 입력하면 OpenDART의 연결/별도 재무제표, 해당 사업보고서의 감사보고서 주석, 관련 수시공시를 분석해 Excel을 생성합니다. **이자비용의 Overall Test는 AI 사용 여부와 관계없이 기본 수행합니다.** 단, 현재 구현은 공시자료 기반 **근사 분석(screening)**이며, 개별 대출의 일별 잔액과 실효금리를 입수해 모든 차입금을 독립 재계산하는 실증적 분석적절차의 완성본은 아닙니다.

## 기능과 수행 순서

1. **재무제표 수집:** 선택한 CFS 또는 OFS의 전기·당기 이자비용과 감가상각비, 재무상태표 차입 관련 잔액을 수집합니다. 당기 사업보고서와 전기 사업보고서에서 해당 기준의 감사보고서 주석을 추출합니다.
2. **변동 선별:** 비용의 증감액 및 증감률을 계산하고 기준에 따른 추가 검토 여부를 판정합니다. 현재 기본값은 **증감률 절댓값 20% 이상 AND 증감액 절댓값 10억 원 이상**입니다. 사용자가 원하면 `--pct 0.10`으로 10%로 변경할 수 있습니다. 이 기준은 OR 조건이 아닙니다.
3. **관련 공시 확인:** 차입·사채·금전대차·증권신고서·증권발행실적보고서·상환·차환, 감가상각 관련 시설투자·유형자산·생산설비 등의 제목을 검색합니다. 공시명, 접수번호, 원문 URL과 발췌문을 저장합니다. 검색은 완전하지 않으며 종속회사 공시를 전수 조사하지 않습니다.
4. **사채 약정금리 구조 비교:** 사업보고서의 차입금·사채 주석에서 식별 가능한 **고정 표면금리 사채의 당기말·전기말 잔액**을 수집합니다. 원화 사채의 기존, 신규(전기말 잔액 0인 경우), 당기말 구성 각각에 대해 원금가중 표면금리를 계산합니다. **기존/신규의 정의는 장부잔액 비교에 기반하므로, 취득·차환·연결범위 변동을 확정적으로 판별하지 못합니다.** 변동금리, 외화사채는 원화 고정금리 가중평균에서 제외하며 원자료 확인이 필요합니다.
5. **사채별 쿠폰이자 보조 추정:** 원금·금리·기간을 찾을 수 있는 고정금리 사채에 대해 `원금 × 금리 × 연중 일수/연간 일수`를 계산합니다. 기존 사채는 전기말 잔액이 유지된 것으로 가정하며, 신규 사채의 발행일이 확인되지 않으면 추정을 생략합니다. **이 보조 추정의 합계는 전체 연결 이자비용의 기대값이 아닙니다.** 사채할인발행차금 상각, 유효이자율, 연중 상환 및 외화환산을 완전히 반영하지 않습니다.
6. **이자비용 Overall Test(기본 실행):** 전전기말·전기말·당기말의 재무상태표 이자발생부채로 두 기간의 **기초·기말 단순평균잔액**을 만들고, 전기의 이자비용/평균잔액으로 추정 부담률을 계산합니다. 차입원가 자본화 금액을 공시 주석에서 식별한 경우 이를 가산한 **자본화 전 이자비용**으로 기대값을 만들고, 당기 자본화금액을 차감합니다.

   ```text
   전기 평균잔액 = (전전기말 이자발생부채 + 전기말 이자발생부채) / 2
   당기 평균잔액 = (전기말 이자발생부채 + 당기말 이자발생부채) / 2
   전기 추정부담률 = (전기 이자비용 + 전기 차입원가 자본화) / 전기 평균잔액
   당기 기대비용 = (전기 추정부담률 × 당기 평균잔액) - 당기 차입원가 자본화
   차이 = 당기 실제 이자비용 - 당기 기대비용
   ```

   자본화 금액이 확인되지 않으면 비용화 이자비용만으로 **더 거친 비교지표**를 산출하고, 해당 한계를 명시합니다. 잔액이나 실제 이자비용이 부족하면 값을 임의로 만들지 않고 '자료 없음' 상태로 둡니다.
7. **잔여 차이 선별:** `max(--amount, |당기 실제 이자비용| × --overall-tolerance)`을 **자동 검토 기준**으로 적용하고 실제−기대값의 절댓값이 이를 넘는지 표시합니다. 기본 상대기준은 5%입니다. 이는 **감사인이 정하는 중요성·허용오차가 아니며, 초과했다고 왜곡표시가 확정되지 않습니다.**
8. **후속 감사절차:** 차입원장·은행조회서·계약서 대사, 원금·기간·변동금리 재계산, 리스이자, 사채 유효이자율, 환율, 차입원가 자본화, 연결범위 변동 등을 검토사항으로 제시합니다. AI를 사용하는 경우 공시상 사실과 가설·미확인 사항을 분리해 추가 설명합니다.

## 설치 및 실행

Python 3.10 이상에서 실행합니다. `.env.example`을 `.env`로 복사하고 `OPENDART_API_KEY`를 설정하세요. AI 설명 기능은 `OPENAI_API_KEY` 설정 시 활성화됩니다. API 키는 GitHub에 업로드하지 마세요.

```bash
pip install -r requirements.txt

# AI 없이도 이자비용 Overall Test 계산 및 Excel 생성
python main.py --company "LG에너지솔루션" --year 2025 --no-ai --output LG_분석.xlsx

# AI 설명과 함께 결과 생성
python main.py --company "대한항공" --year 2025 --output 대한항공_분석.xlsx

# 비용 증감 선별 기준을 10%/10억으로 변경하고 Overall Test 검토 기준을 3%로 설정
python main.py --company "LG에너지솔루션" --year 2025 --pct 0.10 --amount 1000000000 --overall-tolerance 0.03

# 별도 재무제표 선택
python main.py --company "대한항공" --year 2025 --basis OFS --output 대한항공_별도.xlsx
```

사업연도는 2016년부터 직전 완료 사업연도까지, 12월 결산 상장기업만 지원합니다. `--cache`로 캐시 경로를 변경할 수 있습니다. `--demo`는 실제 공시가 아닌 합성 자료이며, 공시 기반 Overall Test를 수행하지 않습니다.

## 구현의 제약 — 반드시 읽으세요

- **개별 차입금 전체의 계약별 Overall Test는 구현되어 있지 않습니다.** 공개 공시만으로 일별 원금, 변동금리의 재설정일, 계약별 이자계산 관행, 자본화 대상, 리스별 유효이자율이 확보되지 않기 때문입니다. 이 프로젝트는 **공시 기반 전체 수준의 근사 검증**과 **확인된 고정금리 사채의 부분적 이자 추정**을 제공하며 둘을 합산하거나 동일한 정확도로 해석하지 않습니다.
- 전기말에 없고 당기말에 있는 사채를 신규로 분류하는 규칙은 추정입니다. 차환·기업결합·재분류는 별도 검토해야 합니다.
- 금리비교는 우선 **KRW 고정금리 사채**만 대상으로 합니다. 원화 장기차입금, 외화차입금, 연동금리부 대출, 리스의 전체 가중평균금리를 계산했다고 주장하지 않습니다.
- 재무상태표 계정명은 기업별로 달라 일부 회사에서 평균 차입잔액을 얻지 못할 수 있습니다. 부채 관련 주석을 활용하는 자동 보완 기능은 범용적으로 구현되어 있지 않습니다.
- 차입원가 자본화액 누락, 연결범위 변화, 회계처리 기준 차이, 분기중 차입 규모 변동은 근사 기대값의 신뢰도를 낮춥니다.
- 예시 사업보고서의 모든 구조와 실제 API 응답을 통합 검증한 상태는 아닙니다. 실제 데이터에서 계산이 누락되면 명확한 근거 없이 수치를 채우지 않습니다.
- `--no-ai`에서도 Overall Test는 실행하지만 **AI 원인 분석은 실행되지 않습니다.**
- 기대이자 차이는 감사인의 분석적절차 검토를 돕는 참고 수치일 뿐 적정의견이나 왜곡표시 결론을 대체할 수 없습니다.

## 코드 구조

- `dart.py` — OpenDART 호출·공시 원문/발췌
- `ai.py` — 선택적 AI 해석, 인용 검증, 1건의 증분 기대값
- `overall.py` — **공시 기반 전체 이자비용 스크리닝**, 식별된 사채 금리·보조 쿠폰이자 계산
- `main.py` — 자료 수집·변동선별·Overall Test 호출·Excel 출력

데이터 출처: [OpenDART](https://opendart.fss.or.kr/guide/main.do). 공시 문구·계약별 일할 방법의 적정성 및 감사증거의 충분성은 별도 검토가 필요합니다.
