# 이자비용 분석적절차 (Interest Expense Overall Test)

## 프로젝트 소개

1. **기업명과 사업연도를 입력하면 OpenDART의 재무제표·감사보고서 주석·관련 공시를 수집하여 이자비용 분석적절차를 수행하는 Python 자동화 도구입니다.**
2. **① 이자비용 차이 분석:** 계산에 사용한 차입 관련 잔액과 이자비용, **기대값의 산출 근거와 계산 과정, 실제값, 차이금액·비율 및 추가 검토 기준 충족 여부**를 검토할 수 있도록 정리합니다.
3. **② AI가 추가 감사절차를 안내합니다:**
   1. 기대값과 실제값의 차이 방향에 따라 확인할 사항
   2. 감사인이 수행할 절차와 필요한 증빙  
   3. 관련 **감사기준서 문단 및 출처**를 이 문서에서 함께 제시합니다.
5. **③ AI가 차입 관련 이슈·공시룰 추출후 분석합니다:** 관련 공시의 **공시일·공시명·원문 링크**와 근거 문구를 추적하고, 주요 내용이 이자비용과 차입금에 미칠 영향 및 감사 시 참고사항을 검토하도록 돕습니다.
6. 이 프로젝트는 **공개자료 기반의 근사 Overall Test 및 위험평가 보조도구**이며, 완결된 실증적 분석적절차나 감사결론을 자동으로 제공하지 않습니다.

### 한눈에 보는 처리 과정

**기업명·사업연도 입력 → OpenDART 재무제표·주석 수집 → 전기 대비 변동 선별 → 이자비용 기대값 산출 → 실제값과 차이 분석 → 관련 공시 탐색·추가 감사절차 제안 → 결과 Excel 생성**

| 단계 | 수행 내용 |
| --- | --- |
| **① 이자비용 차이 분석** | **전전기말·전기말·당기말 차입성부채**, 전기·당기 이자비용, 확인 가능한 차입원가 자본화 금액을 수집합니다. 기초·기말 평균잔액과 **전기 추정 이자부담률**로 당기 기대값을 추정한 뒤 **실제값 − 기대값**을 계산합니다. 전기 대비 증감액·증감률과 별도로, 기대값과 실제값의 차이에 대한 **추가 검토 기준 충족 여부**를 판정합니다. 각 수치의 자료 부족 여부와 계산상 한계도 표시합니다. |
| **② 추가 감사절차** | **실제 이자비용이 기대값보다 큰 경우** 신규차입·금리상승·미지급이자·자본화 감소 등을, **작은 경우** 상환·금리하락·차입원가 자본화·이자비용 누락 가능성 등을 *원인 후보*로 검토합니다. 차입금명세서, 약정서, 은행조회서, 이자지급명세, 원리금상환표, 총계정원장, 자본화 계산자료 등을 이용한 추가 절차를 제안합니다. 감사기준서 **520 문단 5·7, 330 문단 6·18, 500 문단 6·7·9, 505 문단 7**과 연결해 아래에 근거를 설명합니다. |
| **③ 차입 관련 이슈·공시** | 차입·사채·상환·차환·증권신고서·증권발행실적보고서 등의 **관련 공시일, 공시명, 접수번호, DART 원본 URL, 원문 발췌**를 수집합니다. **신규차입 규모와 시점, 조달금리, 상환·차환, 담보·보증조건** 등을 이자비용 변동과 대조할 참고사항으로 제시합니다. 공시는 원인을 확정하는 증거가 아니라 감사인이 계약·원장 등으로 확인할 단서입니다. |

> **AI의 역할:** AI 연결은 선택 사항입니다. 사용 시 공시에서 **확인된 사실**, **변동 원인 후보**, **추가 확인할 사항**을 구분해 설명합니다. 원문 인용 및 수치 입력은 Python에서 일부 검증하며, AI가 제시한 원인이나 위험을 사실 또는 감사결론으로 자동 확정하지 않습니다.

**현재 구현 범위:** 위의 ①~③은 README의 **핵심 분석 결과 분류**입니다. 현재 실행 결과는 아래에 설명한 **4개 Excel 시트**로 생성됩니다. 특히 **감사기준서 문단·출처**, **차이 방향별 증빙 목록** 및 **공시별 감사 참고사항**은 이 README에서 안내하는 검토 가이드이며, 모두가 Excel의 개별 열에 자동 작성되는 것은 아닙니다.

## ① 이자비용 차이 분석 — 기대값·실제값·차이

### 사용 자료와 계산 과정

| 항목 | 자료·계산 내용 |
| --- | --- |
| **계산에 사용한 자료** | 전전기말·전기말·당기말 이자발생부채 잔액, 전기·당기 이자비용, 확인 가능한 전기·당기 자본화 차입원가 (OpenDART 재무제표 및 감사보고서 주석) |
| **전기 평균 이자발생부채** | (전전기말 잔액 + 전기말 잔액) ÷ 2 |
| **당기 평균 이자발생부채** | (전기말 잔액 + 당기말 잔액) ÷ 2 |
| **전기 추정 이자부담률** | (전기 이자비용 + 전기 자본화 차입원가) ÷ 전기 평균 이자발생부채 |
| **당기 기대이자비용** | 전기 추정 이자부담률 × 당기 평균 이자발생부채 − 당기 자본화 차입원가 |
| **실제값** | OpenDART에서 조회·검증된 당기 이자비용 |
| **차이금액** | 당기 실제 이자비용 − 당기 기대이자비용 |
| **차이·변동비율** | **전기 대비 증감률** = (당기 실제 − 전기 실제) ÷ |전기 실제|. **기대값 대비 차이율(참고 계산)** = (당기 실제 − 당기 기대) ÷ |당기 기대|. 분모가 0 또는 미확인이라면 산정하지 않습니다. 현재 Excel에는 **전기 대비 증감률**과 **기대값 대비 차이금액**이 출력되며, **기대값 대비 차이율은 별도 자동 출력 항목이 아닙니다.** |
| **추가 검토 기준 충족 여부** | **|실제 − 기대| ≥ max(절대금액 기준, |당기 실제| × 상대기준)** 이면 검토 대상으로 표시합니다. 현재 기본값은 **10억원 또는 당기 실제 이자비용의 5% 중 큰 금액**입니다. |

**계산의 전제:** 차입원가 자본화 자료가 확인되지 않으면 비용화 이자비용만을 사용한 근사 비교로 처리하며, 전체 차입원가를 검증한 것처럼 표시하지 않습니다. 기초·기말 단순평균은 신규차입·중도상환·금리재설정·환율 변동의 시점별 영향을 충분히 반영하지 못합니다. 차이는 오류 확정이 아닌 **추가 검토 신호**입니다.

**증감 선별 기준과 기대값 차이 검토 기준은 서로 다릅니다.** 현재 main 브랜치의 전기 대비 공시 탐색 기본 조건은 **절대 증감률 20% 이상 AND 절대 증감액 10억원 이상**입니다(명령어의 --pct, --amount로 변경). 반면 기대값과 실제값 비교는 위의 **max(절대금액, 상대금액)** 방식입니다(--overall-tolerance). 두 기준은 감사기준서가 정한 중요성이나 수용가능 차이금액을 자동 산출한 것이 아닙니다.

## ② 추가 감사절차 — 차이 방향·필요 증빙·감사기준

아래는 **감사인이 판단해 수행할 후속 절차의 예시**입니다. 차이가 같은 방향으로 발생하더라도 회사의 거래·약정·회계처리에 따라 원인은 달라질 수 있습니다.

| 차이 방향·검토사항 | 수행할 감사절차 | 필요한 증빙·원천자료 |
| --- | --- | --- |
| **실제 > 기대**: 신규차입, 변동금리 상승, 연중 조달 시점, 미지급이자 또는 비용화 비중 증가 | 차입·상환일별 잔액과 약정금리를 이용해 **독립적 이자 재계산**; 전기 대비 신규차입 및 금리 변경 대사; 미지급이자 기간귀속 확인 | 차입금명세서, 신규·변경 약정서, 은행조회서, 이자율 통지서, 원리금상환표, 이자지급내역, 총계정원장 |
| **실제 < 기대**: 조기상환, 금리 인하, 자본화 증가 또는 비용 누락 가능성 | 상환시점·원금 감소 확인; 금융비용 계정의 **완전성** 검토; 차입원가 자본화 요건·금액 검토; 장부·주석 대사 | 상환확인서, 은행거래내역, 차입금 원장, 건설중인자산·자본화 계산명세, 관련 계약서 |
| **실제와 기대의 차이가 크거나 설명되지 않음** | 경영진에 질의하고 답변을 **독립 증빙으로 뒷받침**; 차이 전체의 원인을 검토; 필요시 세부테스트 확대 및 위험평가 재검토 | 경영진 설명서, 금융기관 회신, 계약별 재계산표, 보조원장·계정별 원장, 결산분개 |
| **비교가능성·계산 입력에 의문**: 외화·리스·연결범위·분류 변경 등 | 당기·전기 자료의 기준 일치 여부 및 기초자료의 완전성·정확성 확인; 환산·유효이자율·리스이자·내부거래 제거 검토 | 감사보고서 주석, 연결조정 명세, 외화차입금 명세, 리스 스케줄, 유효이자율 상각표 |

## ③ 차입 관련 이슈·공시 — 원본 추적과 감사 참고사항

| 확인할 항목 | 수집·검토 내용 |
| --- | --- |
| **공시일** | OpenDART 공시 목록의 접수일 |
| **공시명** | 차입·사채·상환·차환·증권발행 등 탐색된 공시의 제목 |
| **주요 내용** | 수집된 원문 발췌에서 신규차입·상환, 금리, 발행·만기, 사용 목적, 담보·보증조건 등의 사실관계를 확인할 단서 |
| **감사 시 참고사항** | 차입 잔액의 증감과 이자비용 발생 시점이 부합하는지, 공시 조건이 차입금명세서·계약서·계정원장과 일치하는지, 추가 증빙이 필요한지 확인 |
| **원본 링크** | **공시 접수번호별 DART URL**과 출처 ID. 공시별 근거를 추적해 원문을 재검토할 수 있습니다. |

**주의:** 현재 ‘관련 공시 근거’ 시트는 **공시명·공시일·접수번호·원본 URL·인용문·출처 ID**를 출력합니다. **‘주요 내용’의 완전한 구조화 요약이나 ‘감사 시 참고사항’이 각 공시별 전용 열로 자동 출력되는 것은 아닙니다.** 공시 제목·제한된 발췌를 통한 검색이므로 모집단의 완전성도 보장하지 않습니다.

## 설치 및 실행

**Python 3.10 이상**에서 실행합니다. 별도의 GUI는 없으며 명령어로 실행합니다. 저장소 폴더에서 의존성을 설치하고 **.env.example**을 **.env**로 복사해 **OPENDART_API_KEY**를 입력합니다. **OPENAI_API_KEY**는 선택적 AI 공시 해석에만 필요합니다.

~~~bash
pip install -r requirements.txt

# AI 없이 이자비용 분석적절차 및 Overall Test 수행
python main.py --company "대한항공" --year 2025 --no-ai --output "대한항공_이자분석.xlsx"

# AI 공시 분석 포함 (OpenAI API 키가 설정된 경우)
python main.py --company "대한항공" --year 2025 --output "대한항공_이자분석_AI.xlsx"

# 전기 대비 선별 조건을 10%와 10억원으로 설정 (현재 코드는 AND 조건)
python main.py --company "대한항공" --year 2025 --pct 0.10 --amount 1000000000 --overall-tolerance 0.03

# 별도재무제표(OFS)로 실행
python main.py --company "대한항공" --year 2025 --basis OFS --no-ai --output "대한항공_별도.xlsx"
~~~

## 구현상 한계

- 공시 기반 **근사 분석**입니다. 계약별 일별 차입잔액, 변동금리 재설정, 사채할인발행차금·유효이자율, 외화·리스 및 연결범위 영향을 완전하게 재계산하지 않습니다.
- 회사별 공시 표 형태와 계정명이 다르므로 원자료가 불충분하면 **자료 없음/확인 필요**로 남깁니다. 누락 수치를 임의로 채우지 않습니다.
- AI 공시 해석은 **선택 기능**이며, 확인된 사실·가설·미확인 사항을 구분하지만 감사를 대신하지 않습니다.
- 현재 **관련 감사기준서 문단·증빙·공시별 감사 고려사항**은 README의 검토 지침이며, Excel에 각각 전용 열로 자동 기재되는 기능은 아닙니다.
- 자동 테스트는 합성 자료 중심입니다. 실제 OpenDART 조회와 개별 기업의 분석 결과는 감사인이 별도로 대사하고 검증해야 합니다.
- **기준 초과는 추가 검토 대상이라는 의미**일 뿐 회계오류나 중요왜곡표시위험의 존재를 확정하지 않습니다.
