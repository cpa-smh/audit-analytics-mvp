# 이자비용·감가상각비 분석적절차 

## 프로젝트 소개

1. **회사명을 입력하면 AI가 이자비용, 감가상각비에 전기 대비 유의미한 변동(전기대비 10%이상, 10억원 이상)이 존재하는지 탐색합니다. 유의미한 변동이 인식된다면, AI가 해당 변동에 관련된 전자공시(사채 발행공시, 유형자산양수결정,신규시설투자 등)를 찾습니다.**
2. **OpenDART의 당기·전기 재무자료와 관련 공시·주석**을 활용해 비용의 증감액·증감률을 계산하고, 설정한 기준에 해당하는 변동을 추가 분석 대상으로 구분합니다.
3. 이자비용은 **신규 차입·회사채 발행, 상환·차환, 차입 규모·금리·기간 변화**, 감가상각비는 **설비 취득·처분, 공장 준공·사용개시, 건설중인자산 대체, 상각방법·내용연수 변경**과의 관련성을 검토하도록 AI에 요청합니다.
4. 분석에 사용한 **공시명·공시일·접수번호·원문 URL·인용문**을 남기고, **공시에서 확인된 사실, 변동 원인 후보, 공시만으로 확인할 수 없는 사항**을 구분합니다.
5. 원금·금리·기간 또는 취득원가·잔존가치·내용연수 등 필요한 자료가 확인되면 **Python으로 간단한 기대값을 계산**합니다. 기댓값과 유의미한 차이가 나는 경우, 설명되지 않은 변동에는 **잠재적 왜곡표시위험 후보와 기준서에 따른 추가감사절차**를 제시합니다.
6. 단, 이는 실제 오류나 중요왜곡표시위험을 확정하지 않습니다.

### 한눈에 보는 처리 과정

**회사명·연도 입력 → OpenDART 재무자료·주석 확보 → 비용 증감 계산·관련 공시 탐색 → AI의 근거 기반 원인 분석 → 기대값 계산·추가 감사절차 제안 → 결과 Excel 생성**

| 단계 | 수행 내용 |
| --- | --- |
| **① 분석 대상 기업을 식별하고 당기·전기 비용을 수집** | 회사명 또는 종목코드로 상장기업을 찾고 **분석연도와 직전연도의 연간 재무자료**를 가져옵니다. 기본은 **연결(CFS)**이며 사용자가 별도(OFS)를 선택하면 해당 자료만 사용합니다. 이자비용·감가상각비와 함께 연도·통화·접수번호를 보관하고, 계정이 없으면 해당 감사보고서의 주석을 발췌합니다. **이자 지급액이나 감가상각·무형자산상각 통합액으로 대체하지 않으며**, 확인되지 않은 금액은 ‘자료 없음’으로 남깁니다. |
| **② Python으로 증감액·증감률을 계산하고 관련 공시를 탐색** | **당기−전기**로 증감액을, **증감액÷전기 절댓값**으로 증감률을 계산합니다. 기본 기준인 **절대 증감률 20% 이상 AND 절대 증감액 10억원 이상**에 해당하거나 비용 금액이 확인되지 않은 계정은 분석연도 중 추가 공시도 제목 키워드로 검색합니다. 이자비용은 **차입·사채·상환·차환**, 감가상각비는 **시설투자·유형자산·생산 관련 공시** 등을 탐색하고, 관련 원문과 출처를 연결합니다. 감소도 분석하며 전기가 0이면 증감률 대신 금액 기준을 적용합니다. |
| **③ AI가 공시 근거를 읽고 비용 변동의 원인 후보를 분석** | 두 계정의 수치와 관련 공시 발췌를 **한 번의 AI 요청**으로 전달합니다. 이자비용은 **차입 규모·금리·발생기간 변화가 비용 변동을 설명하는지**, 감가상각비는 **설비 취득·준공·실제 사용개시가 상각비 변동과 연결되는지** 검토하도록 요청합니다. AI는 **확인된 사실·원인 후보·미확인사항·위험 후보·추가 감사절차**를 구조화된 형식으로 제안합니다. 공장 건설이나 투자 결정만으로 감가상각이 시작되었다고 가정하지 않습니다. |
| **④ 원문 인용을 검증하고 자료가 충분한 경우 기대값을 계산** | Python이 **사실에 붙인 인용문이 제공한 원문에 존재하는지** 확인하고, 일치하지 않는 사실 인용은 제외합니다. AI가 누락 금액을 추출한 경우 숫자·단위·연도·계정 및 출처 범위를 검사한 뒤 반영합니다. 근거가 갖춰지면 이자는 **원금×연이율×기간 비율**, 정액법 감가상각은 **(취득원가−잔존가치)÷내용연수×사용가능 기간 비율**로 계산합니다. **연간 전체 비용에 대한 기대값일 때만 실제 비용과 차이**를 계산하고, 개별 차입·설비의 기대값은 증분 분석으로 표시합니다. 기존·신규 금리 비교 시에는 통화·만기·담보 등 조건 차이를 추가 확인하도록 안내합니다. |
| **⑤ 미확인 변동에 대한 추가 감사절차를 제시** | 공시만으로 충분히 설명되지 않는 사항은 **검토 대상과 필요한 자료**로 남깁니다. 이자비용에는 **차입금 명세·은행조회서·계약서 대사, 약정금리 재계산, 미지급이자 기간귀속 및 자본화 검토**, 감가상각비에는 **자산 명세·취득 및 처분 증빙 대사, 준공·검수와 사용가능일 확인, 내용연수·잔존가치·상각 계산 검토** 등을 제안할 수 있습니다. 원인이 확인되지 않았다는 이유만으로 오류나 위험이 존재한다고 단정하지 않습니다. |
| **⑥ 분석 결과와 공시 근거를 Excel 두 시트로 출력** | **‘분석적절차 결과’** 시트에 당기·전기 금액, 증감액·증감률, 확인 사실, AI 원인 후보, 기대값·차이와 적용 범위, 금리 비교, 위험 후보, 추가 절차 및 분석 상태를 정리합니다. **‘관련 공시 근거’** 시트에는 계정별 공시명·공시일·접수번호·URL·인용문·출처 ID를 저장합니다. 숫자 서식·필터·틀 고정을 적용하고 **자료 없음·AI 미사용 또는 실패·비교 유보** 상태도 표시해 사람이 근거와 결과를 함께 검토할 수 있도록 합니다. |

> **AI의 역할:** AI는 검색된 공시의 사실과 비용 변동의 관련성을 분석하고 **원인 후보와 추가 확인사항**을 제안합니다. 공시 검색·증감 계산·입력값 및 인용 검증·기대값 계산·Excel 저장은 Python이 담당합니다. AI는 선택 기능이며 기업 1곳당 최대 1회 호출합니다. AI 연결이나 근거가 부족해도 가능한 수치 분석과 Excel 생성은 계속합니다.

**분석 범위:** 위험평가 분석적절차를 지원하는 MVP입니다. 공시 검색 건수와 발췌 범위에 제한이 있고, 인용 일치가 해석의 정확성까지 보증하지는 않습니다. 기대값은 현재 구현에서 금액 단위·날짜 등 입력 근거를 확인할 수 있는 경우만 계산하며, 자료가 부족하면 임의의 금액이나 사용개시일을 만들지 않습니다.

**실행 방식:** 별도 화면 프로그램(GUI) 없이 명령어로 실행합니다. Python 3.10 이상, 12월 결산 상장기업을 대상으로 하며, 공시 수집에는 OpenDART 키가 필요합니다. AI 분석을 사용할 때만 OpenAI 키를 추가합니다. `--output`으로 Excel 저장 경로를 지정하며, 파일 생성에 Excel 설치는 필요하지 않습니다.

## 설치·실행

```bash
pip install -r requirements.txt
```

`.env.example`을 `.env`로 복사하고 `OPENDART_API_KEY`를 설정합니다. AI를 사용할 때만 `OPENAI_API_KEY`, `OPENAI_MODEL`을 설정합니다. 모델 기본값은 `gpt-4.1-mini`이며 계정에서 사용할 수 있는 구조화 응답 지원 모델로 변경할 수 있습니다. 키는 Git에 올리지 않습니다.

```bash
python main.py --company "삼성전자" --year 2025 --output "분석결과.xlsx"
python main.py --company "삼성전자" --year 2025 --no-ai --output "수치분석.xlsx"
python main.py --company "가상기업" --year 2025 --demo --output "가상예시.xlsx"
```

`--basis CFS`가 기본이며 별도는 `--basis OFS`입니다. 자동 대체하지 않습니다. 기준은 **절대 증감률 20% 이상 AND 절대 증감액 10억원 이상**입니다. 감소도 탐색합니다. 전기 0은 증감률을 계산하지 않고 금액 기준으로 탐색합니다.

```bash
python main.py --company "삼성전자" --year 2025 --pct 0.15 --amount 500000000 --rate-pp 1.0
```

## 처리 방식

- OpenDART API 하나만 사용합니다. 기업코드 → 연간 전체 재무제표 → 해당 접수번호의 연결/별도 감사보고서 → 유의적 변동 관련 주요 공시 순입니다.
- 이자 지급액을 이자비용으로, 감가상각·무형자산상각 통합액을 감가상각비로 대체하지 않습니다. 명확한 계정이 없으면 주석을 탐색합니다. AI 미사용 시 주석 발췌는 제공하지만 주석 금액의 의미 추출은 수행하지 않습니다.
- AI는 두 계정의 발췌를 묶어 **최대 1회** 호출합니다. 통신 실패나 인용 오류에 재질문하지 않습니다. 확인 사실·원인 후보·미확인사항·위험 후보·추가 감사절차를 구분합니다. 인용문 및 수치의 원문 존재 여부만 확인하며 의미의 정확성을 보장하지 않습니다.
- 비용 기대값은 근거가 있는 입력만 Python으로 계산합니다. 이자: 원금×연이율×연중 해당 일수/연간 일수. 감가상각: (취득원가−잔존가치)/내용연수×사용가능 기간 비율(정액법). 단위가 원이고 날짜가 ISO 형식으로 직접 확인되는 경우에 한합니다. 실제 약정의 일수계산 관행과 차이가 있을 수 있습니다.
- 개별 신규 차입·설비 기대값은 증분 분석으로 표시하며 연간 전체 비용에서 빼지 않습니다. 금리 비교는 통화·만기·담보 등 조건 차이 확인을 요구합니다. 공장 투자 결정만으로 사용개시를 가정하지 않습니다.
- 원문·성공한 API 응답과 AI 결과를 `.cache/`에 저장합니다. 정정공시 반영을 다시 확인하려면 새 `--cache` 경로를 사용하거나 기존 캐시를 삭제하세요. 키와 오류 응답은 캐시에 저장하지 않습니다.

## 결과: 정확히 두 시트

1. **분석적절차 결과**: 비용, 증감, 확인 사실, 원인 후보, 기대값·차이, 금리 비교, 위험 후보, 추가 절차, 상태.
2. **관련 공시 근거**: 계정, 제목, 공시일, 접수번호, URL, 원문 인용 및 출처 ID.

`--demo`는 실제 기업과 무관한 합성 예시입니다. 이자비용 100억→130억(증가 30억·30%), 감가상각비 200억→260억(증가 60억·30%)을 출력합니다. 실측 자료가 없으면 `자료 없음`이며, 0으로 채우지 않습니다.

## 한계 및 검증 범위

최소 기능 제품으로, 모든 기업의 사용자 정의 계정명·주석 배치를 지원하지 않습니다. 감사보고서 첨부에서 연결/별도 구분이 확실하지 않으면 주석 수집을 생략합니다. 감가상각비의 사용권자산 포함 범위, 비용 기능별 배분, 자본화와 비용 인식의 차이는 원문 확인이 필요합니다. 금액 수집 경로가 연도별로 다르면 비교를 유보합니다.

추가 공시는 분석연도 중 제출된 제목 키워드 일치 공시 중 최근 8건, 연간 감사보고서는 계정별 최대 4개 발췌를 사용합니다. `--max-filings`, `--max-excerpts`로 늘릴 수 있습니다. 검색 범위 밖·발췌 누락 가능성이 있으며 “원인 미확인”은 “원인이 없음”을 뜻하지 않습니다. 이후 공시나 종속기업의 별도 공시까지 전수 검색하지 않습니다.

검증: 합성 OpenDART 응답으로 수집·공시발췌 연결, 증감 계산, 기대값 계산, 인용 검증 및 모의 AI 응답의 Excel 2개 시트 저장을 확인했습니다. **실제 OpenDART 키를 사용한 통신, 실제 OpenAI 모델 응답, 모든 기업의 주석 추출은 미검증**입니다. `--demo` 실행에는 어떤 외부 API도 호출하지 않습니다.

공식 자료: [OpenDART](https://opendart.fss.or.kr/guide/main.do), [OpenAI 구조화 응답](https://developers.openai.com/api/docs/guides/structured-outputs).
